# Take on AI

AI is a very very good tool. But don't over use it, and don't let it spoonfeed you answers, even if you can read what the code does the main point of programming is coming up with a plan on how to write a portion of code, being able to problem solve and write it, and fixing any errors when it breaks.

<b>Coding and programming are not the same thing!</b>

- programming: coming up with a plan, and fixing it when it breaks.
- coding: knowing how a program works but not being able to break it down and write it yourself.

A coder lets AI generate all the code and can understand what it does. A programmer can come up with a plan, be able to program it, and can fix it when it breaks.

**Rule:** any code from AI starts with `// AI start` and ends with `// AI end`.
